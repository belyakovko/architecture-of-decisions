# Архитектура решений

Публичный интерактивный сайт для GitHub Pages. Исходные записи — Markdown в папке `entries/`.

## Публикация

Создайте файл `entries/<id>.md`, например:

```md
---
id: example-01
title: "Название мысли"
date: 2026-10-26
summary: "Короткое описание"
status: published
visibility: public
topics:
  - Аналитика
  - Управление
links: []
---

# Название мысли

Текст статьи.
```

После коммита GitHub Actions пересобирает `data/content.json`. Сайт использует этот файл для карты, размеров узлов, ссылок и списка статей. Связи между областями возникают, когда одна запись относится к двум или более темам; `links` задаёт ссылки на другие публичные записи по `id`. Размер круга зависит от числа опубликованных записей.

**Безопасность:** исходники личного архива здесь отсутствуют. Публикация выполняется **только после отдельного одобрения**; не копируйте личный текст сюда без разрешения. Условие `status: published` + `visibility: public` дополнительно проверяется генератором, но не делает загруженные в публичный репозиторий черновики приватными.

Пустая карта до первой публикации — ожидаемое поведение. Данные для карты никогда не подменяются фиктивными областями.


## Проектные кейсы

Проекты живут отдельно от статей в `projects/*.md`. Для публичного проекта обязателен такой же принцип явной публикации: `status: published` и `visibility: public`. Пример первого кейса — `projects/lagunaos.md`.

Дополнительные поля проекта:
- `stage` — текущая стадия, а не обещанный результат.
- `role` — реальная профессиональная роль.
- `topics` — области знаний, через которые кейс связан с картой.
- `links` — ID опубликованных статей с относящимися к кейсу принципами.

Генератор `scripts/build-content.cjs` поддерживает **два раздельных манифеста**: `data/content.json` (статьи) и `data/projects.json` (проекты). Публичные проекты не увеличивают счётчик статей и не раскрывают приватные черновики.

Важно: перед публикацией нового кейса проверяйте отсутствие коммерческой тайны, персональных данных, конфигурации систем и неподтверждённых экономических эффектов.
